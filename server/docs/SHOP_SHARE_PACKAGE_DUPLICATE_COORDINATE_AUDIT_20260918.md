- `server/cmd/protocol-probe/shop_catalog.go`: 기존 행 검증 이후 `map[[2]int32]string`으로 `(page,position)` 선점 좌표를 기록하고, 중복 시 상점 ID·행 번호·페이지·칸·충돌 상품 ID를 포함한 오류 반환. 기존 가격·수량·상품 ID·구매 SQL·패킷 정의를 바꾸거나 실제 원본 INI를 덮어쓰지 않는다. 해당 문제 상점은 충돌이 있는 소스에서 **전부 로드 거부**되므로 이것이 원본 중복 행을 해결하거나 상품을 자동 배치한다는 주장은 하지 않는다.
